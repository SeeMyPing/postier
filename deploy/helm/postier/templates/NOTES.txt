Postier {{ .Chart.AppVersion }} is installing in namespace {{ .Release.Namespace }}.

Wait for the roles:

  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "postier.fullname" . }}-api

KumoMTA starts once the operator has written its configuration.

Then declare who sends, from which domain, with which key. In a namespace of
your choice, which is the tenant:

  kubectl apply -f deploy/examples/acme.yaml

  kubectl -n acme get sendingdomains
  kubectl -n acme get sendingdomain notifications -o jsonpath='{range .status.requiredRecords[*]}{.type}{"\t"}{.name}{"\t"}{.value}{"\n"}{end}'
{{- if .Values.operator.skipDNSVerification }}

DNS verification is DISABLED on this installation: any declared domain can
send. Fine for a test cluster, never for production.
{{- else }}

Publish the listed DNS records: the domain becomes Ready once they are seen.
{{- end }}

The API key is in the Secret named after the ApiCredential:

  kubectl -n acme get secret backend -o jsonpath='{.data.api-key}' | base64 -d

Send an email:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "postier.fullname" . }}-api 8080:{{ .Values.api.service.port }}
{{- if .Values.mailpit.enabled }}

Every message lands in Mailpit:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "postier.fullname" . }}-mailpit 8025:8025
{{- end }}
